# Изменения в исправленной версии ЛР4

1. Добавлен `scripts/session.lua`: операции SET/GET/DEL выполняются одним Lua-скриптом Redis.
2. Добавлен `core/redis_sessions.py`; скрипт регистрируется при запуске FastAPI и используется при создании, проверке и удалении cookie-сессии.
3. Удалена настройка `MODERATOR_USERNAMES`: публичная регистрация выдаёт только роль `user`; роль `moderator` назначается администратором БД.
4. Исправлен путь стандартного изображения: используется реально присутствующий `static/media/default-greenhouse.jpg` вместо отсутствующего SVG. Для уже существующей БД приведён SQL UPDATE в README_LR4.md.
5. В API обработчике добавлена защита от вычисления логарифма при концентрации CO₂ меньше либо равной нулю.
6. Обновлена ER-диаграмма: перечислены все поля трёх фактических таблиц; nullable-поля отмечены `NULL`, остальные `NOT NULL`; связи и составной PK таблицы likes показаны явно.
7. Добавлена UML-диаграмма классов `diagrams/lr4_class.drawio`.
8. Диаграмма последовательности обновлена: показаны Lua SET/GET, формат страницы приведён к A4 portrait.
9. Уточнена цветовая иерархия заголовков для светлых форм и тёмной ленты.
10. В README и отчёт добавлено объяснение формулы расчёта температуры.

## Проверки

- Выполнен `python -m compileall -q api core main.py models repositories schemas`.
- XML-файлы диаграмм проверены на корректный разбор XML.
- Полный запуск приложения с PostgreSQL и Redis требует локально запущенных Docker-контейнеров и настройки `.env`; эти параметры намеренно не включены в архив.

# Greenhouse Gases

Веб-сервис для работы с данными о парниковых газах и расчёта температуры Земли в зависимости от концентрации газов в атмосфере.

Проект выполнен на **FastAPI** с использованием серверных HTML-шаблонов **Jinja2**. Данные хранятся непосредственно в Python-коллекции без использования базы данных.

## Тема проекта

**Прогноз температуры на Земле в зависимости от содержания парниковых газов в атмосфере.**

В системе представлены различные парниковые газы:

* углекислый газ (CO₂);
* метан (CH₄);
* оксид азота (N₂O);
* водяной пар (H₂O);
* гексафторид серы (SF₆).

Для каждого парникового газа хранятся название, химическая формула, концентрация, потенциал глобального потепления, описание, количество лайков, статус и ссылки на медиафайлы.

## Модель данных

Основная коллекция находится в:

```text
data/collections.py
```

Она называется:

```python
greenhouse_gases
```

Каждый элемент коллекции содержит:

```python
{
    "id": 1,
    "name": "Углекислый газ",
    "formula": "CO2",
    "concentration_ppm": 420.0,
    "global_warming_potential_100y": 1.0,
    "description": "...",
    "likes": [1, 2, 3],
    "status": "published",
    "image_key": "...",
    "video_key": "..."
}
```

### Статусы

Используются три состояния:

```text
draft
published
deleted
```

* `published` — опубликованный парниковый газ;
* `draft` — черновая запись для страницы расчёта;
* `deleted` — удалённая запись.

Удалённые записи не выводятся в каталоге и ленте.

## Расчёт изменения температуры

Расчёт реализован в `api/handlers.py` функцией:

```python
calculate_temperature_change()
```

Используется упрощённая формула:

```text
ΔT = S × log₂(C / C₀)
```

где:

* `C` — заданная концентрация CO₂;
* `C₀ = 280 ppm` — базовая доиндустриальная концентрация;
* `S = 3 °C` — используемая в учебном проекте чувствительность климата.

В коде:

```python
REFERENCE_CO2_PPM = 280.0
CLIMATE_SENSITIVITY_C = 3.0
```

Расчёт применяется к записи с формулой `CO2`.

Для остальных парниковых газов значение изменения температуры в текущей реализации не рассчитывается.

## Страницы приложения

### Лента парниковых газов

```text
GET /greenhouse-gases/{greenhouse_gas_id}
```

Пример:

```text
http://127.0.0.1:8000/greenhouse-gases/1
```

Страница отображает конкретный опубликованный парниковый газ.

На странице используются:

* название;
* химическая формула;
* концентрация;
* описание;
* количество лайков;
* изображение;
* видео.

Для перехода к следующему опубликованному объекту используется GET-параметр:

```text
?next=true
```

Пример:

```text
/greenhouse-gases/1?next=true
```

Переход выполняется на следующий опубликованный парниковый газ.

### Каталог

```text
GET /greenhouse-gases/catalog
```

Каталог содержит опубликованные парниковые газы.

Удалённые и черновые записи в каталог не попадают.

Для фильтрации используется GET-параметр:

```text
?concentration=420
```

Например:

```text
/greenhouse-gases/catalog?concentration=420
```

Фильтрация выполняется на стороне сервера.

В текущей реализации отображаются опубликованные записи, концентрация которых не превышает переданное значение:

```python
greenhouse_gas["concentration_ppm"] <= concentration
```

### Страница заявки на расчёт

```text
GET /greenhouse-gases/request
```

Для передачи концентрации используется GET-параметр:

```text
?concentration=420
```

Пример:

```text
/greenhouse-gases/request?concentration=420
```

Страница использует единственный объект со статусом `draft`.

Переданная концентрация используется для расчёта изменения температуры для CO₂.

## Обработчики

Основные HTTP-маршруты находятся в:

```text
api/handlers.py
```

Роутер FastAPI:

```python
router = APIRouter()
```

В обработчиках реализованы:

* получение опубликованных парниковых газов;
* подготовка данных для шаблонов;
* формирование URL медиафайлов;
* расчёт изменения температуры;
* отображение каталога;
* фильтрация;
* отображение отдельного парникового газа;
* переход к следующему опубликованному объекту;
* отображение страницы заявки на расчёт.

## Подготовка данных

Перед передачей объекта в Jinja2 используется функция:

```python
prepare_greenhouse_gas()
```

Она добавляет к объекту дополнительные значения:

```text
likes_count
image_url
video_url
```

Количество лайков определяется непосредственно из списка пользователей:

```python
len(greenhouse_gas["likes"])
```

Таким образом, отдельное поле для количества лайков в коллекции не требуется.

## Архитектура приложения

Приложение построено на FastAPI.

Основная точка входа:

```text
main.py
```

В ней создаётся приложение:

```python
app = FastAPI(...)
```

Подключаются статические файлы:

```python
app.mount("/static", StaticFiles(directory="static"), name="static")
```

